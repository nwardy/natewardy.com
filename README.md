# Nathan Wardy - Resume Website

A clean, minimal, and professional resume website built with modern web technologies. Features a responsive design with an off-white creme color palette and monochrome accents for optimal readability and professional presentation.

## Features

- **Responsive Design** - Optimized for desktop, tablet, and mobile devices
- **Minimal Aesthetic** - Clean off-white/creme design with monochrome accents
- **Professional Layout** - Well-structured sections highlighting experience, skills, and projects
- **Smooth Navigation** - Fixed header with smooth scrolling to sections
- **Accessibility** - WCAG compliant with proper focus states and semantic HTML
- **Fast Loading** - Optimized CSS and minimal JavaScript for quick load times
- **Print Friendly** - Optimized print styles for PDF generation

## Technology Stack

- **HTML5** - Semantic markup structure
- **CSS3** - Modern styling with CSS custom properties (variables)
- **Vanilla JavaScript** - Clean, dependency-free interactions
- **Responsive Grid/Flexbox** - Modern layout techniques

## Design System

### Color Palette
- **Primary Background**: `#faf9f6` (Off-white creme)
- **Secondary Background**: `#f5f4f1` (Slightly darker creme)
- **Text Primary**: `#2c2c2c` (Dark charcoal)
- **Text Secondary**: `#4a4a4a` (Medium gray)
- **Accent**: `#3a3a3a` (Monochrome accent)

### Typography
- **Primary Font**: Georgia, Times New Roman (serif)
- **Secondary Font**: Helvetica Neue, Arial (sans-serif)
- **Monospace**: Monaco, Menlo (for technical elements)

### Spacing System
Based on a consistent scale using CSS custom properties for maintainability.

## Getting Started

1. **Clone or download** this repository
2. **Open `index.html`** in your web browser
3. **Customize content** by editing the HTML sections
4. **Modify styles** by updating the CSS files
5. **Add assets** like profile photos and project images
